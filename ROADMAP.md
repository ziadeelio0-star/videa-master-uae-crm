# Videa Master Pro — Roadmap (suggested future enhancements)

These were not part of the original request. They are proposed next steps whenever you're ready.

1. **Per-client tool recommendations** — Use each client's machines and historical tool usage to surface suggested tools, with a rules or LLM-assisted engine.
2. **Invoice PDF export / print view** — A one-click printable / downloadable invoice for each transaction group, using the catalog letterhead.
3. **Historical stock levels and reorder alerts** — Extend the schema with a `stock` table, record inbound/outbound movements, and surface low-stock warnings.
4. **Notifications for overdue transactions** — A daily scheduled task that emails / in-app-notifies the owner about invoices that have just crossed into "overdue".
